# 6-Week Study Plan — CCDV-F

Allocate time by domain weight. Suggested ~10-12 hrs/week.

## Week 1 — Domain 2 (Applications & Integration) part 1 (33.1%)
- API Mechanics: Messages, streaming, vision, thinking, caching, vendors, batch vs realtime.
- Error handling, retries, status codes.
- Hands-on: build a small Claude app with streaming + tool + caching.

## Week 2 — Domain 2 part 2 + Domain 5 (Model Selection) (33.1% + 16.8%)
- SE Foundations (REST, JSON, async, git, SDLC, review, refactor).
- App Design (interfaces, content boundaries, schemas, session hygiene, plugins).
- Config Management (CLAUDE.md, settings.json, pinning, prompt versioning).
- Requirements + Systems Life Cycle.
- Domain 5: LLM fundamentals, model tiers, cost/token management, routing, optimization order.

## Week 3 — Domain 1 (Agents & Workflows) (14.7%) + Domain 6 (Prompt & Context) (11.0%)
- Agent architecture, construction (SDK, loops, hooks, deployment), patterns (chaining, routing, parallelization, orchestrator-workers, evaluator-optimizer), frameworks.
- Hands-on: build an agent with subagents + hooks.
- Prompt/context engineering: context window, rot, attention, pruning, compaction, isolation, RAG; prompt parts, XML, few-shot, templates, refinement, sanitization, output handling.

## Week 4 — Domain 8 (Tools & MCPs) (10.6%) + Domain 7 (Security) (8.1%)
- Tool definitions, loop, tool_choice, parallel, built-in vs custom, descriptions, errors, approval.
- MCP: primitives, transports, server authoring, tradeoffs.
- Security: injection, jailbreak, trust boundaries, guardrails, hooks, secrets, IAM, PII, safe deployment.
- Hands-on: build an MCP server + guardrails.

## Week 5 — Domain 3 (Claude Code) (3.1%) + Domain 4 (Eval/Debug) (2.6%) + review
- Claude Code operation, CLAUDE.md hierarchy, modes, settings.
- Debugging 4-step method, error types, evals (golden sets, LLM-as-judge, regression, logging).
- Review weak areas; re-read cheat sheet.

## Week 6 — Practice & polish
- Drill practice questions + official sample questions.
- Timed mock (53 questions / 120 min).
- Final review of top 6 topics and cheat sheet.
- Exam logistics: ID, Pearson VUE, NDA.

## Daily habits
- 30 min flashcards (glossary).
- Build something small each week (hands-on is weighted heavily).
- Self-assess against every sub-skill objective.
