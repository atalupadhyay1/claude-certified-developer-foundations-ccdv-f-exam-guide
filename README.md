# Claude Certified Developer – Foundations (CCDV-F) Exam Guide

Study material for the Udemy course **"Claude Certified Developer Foundations (CCDV-F) Exam Guide"**
and for the official **Claude Certified Developer – Foundations (CCDV-F)** certification exam.

## Exam at a glance

| Attribute | Detail |
| --- | --- |
| Exam code | CCDV-F |
| Questions | 53 (multiple-choice + multiple-response) |
| Time | 120 minutes |
| Delivery | Proctored (online or test center) via Pearson VUE |
| Passing score | Scaled 720 / 1000 |
| Fee | US$125 |
| Validity | 12 months |
| Blueprint | v1.0, effective July 2026 |

## How to use

1. Read `00-exam-overview.md` for format and scoring.
2. Work domains in weight order: 2 → 5 → 1 → 6 → 8 → 7 → 3 → 4 (or follow `study-plan.md`).
3. Self-assess against each sub-skill objective (weights in each file).
4. Drill `practice-questions.md` and the official sample questions.
5. Keep `cheat-sheet.md` for last-week review.
